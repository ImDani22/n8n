Automated video production studio

Create, manage and publish video content from one panel.

N8N YouTube Studio is a self-hosted desktop production panel that helps its owner generate, review and publish video content to connected social-media accounts. External accounts are connected only after explicit user authorization.

Content production

Generate scripts, narration, visuals and final videos in a supervised or automated workflow.

Account connections

Connect supported social-media accounts through OAuth and manage those connections from the panel.

Publishing control

Publish only to accounts explicitly connected by the account owner.

TikTok integration

The planned TikTok integration uses TikTok's official authorization flow. The app may request basic profile information and publishing permissions only when the user chooses to connect a TikTok account.

This project is independently operated and is not affiliated with, endorsed by, or sponsored by TikTok.
